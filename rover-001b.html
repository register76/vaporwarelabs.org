Rover-001b

A modular RC rover platform built for clean wiring, Raspberry Pi integration, and future autonomy experiments.

Project Overview

Rover-001b is the next evolution of the VaporWare Labs rover platform. It starts as a reliable RC-controlled rover and grows toward a mobile Project Vapor node with onboard computing, telemetry, sensors, and eventually autonomous navigation.

Current Architecture

  • Arduino Nano Every for real-time motor and RC control
  • RadioMaster Boxer transmitter with ER4 receiver
  • TB6612FNG motor driver
  • TT gear motors
  • 2020 aluminum extrusion frame
  • Raspberry Pi 5 planned for high-level control

Design Goals

  • Clean, modular, serviceable wiring
  • Stable RC driving baseline
  • Separate real-time control from high-level compute
  • Support future sensors, camera, and telemetry
  • Eventually integrate with Home Assistant and Project Vapor

Status

Rover-001b is currently in hardware bring-up. The frame, motor wiring, receiver wiring, and Arduino control path are being tested. The next milestone is reliable RC control followed by Raspberry Pi integration.

Roadmap

  1. Complete RC control bring-up
  2. Finalize 5V power system
  3. Add Raspberry Pi 5 high-level computer
  4. Create Pi-to-Arduino command and telemetry interface
  5. Add camera and basic vision experiments
  6. Integrate with Project Vapor / Home Assistant
  7. Explore docking, charging, and indoor navigation

Why This Project Matters

Rover-001b is more than a small robot. It is a testbed for embedded control, mechanical design, power distribution, computer vision, automation, and human-centered smart-home robotics.
