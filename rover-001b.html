Rover-001b

A modular RC rover platform built around Arduino, Raspberry Pi, and 2020 aluminum extrusion. Designed as a clean, serviceable robotics platform and future mobile node for Project Vapor.

View Source Code ← Back to Projects
Overview

Purpose-Built for Experimentation

Rover-001b is the second-generation VaporWare Labs rover platform. It begins as a robust RC-controlled rover and evolves into a mobile robotics testbed for autonomy, computer vision, Home Assistant integration, and autonomous docking.

Current Hardware

Architecture

  • Arduino Nano Every
  • RadioMaster Boxer + ER4 receiver
  • TB6612FNG motor driver
  • TT gear motors
  • Raspberry Pi 5 (planned)
  • 2020 aluminum extrusion frame
  • 3D printed mounting brackets

Current Status

Hardware bring-up is underway. Motor wiring, RC receiver, and Arduino control software are being validated. Next milestone: stable RC control and power-system refinement.

Design Goals

Engineering Priorities

  • Clean, modular, serviceable wiring
  • Reliable RC control baseline
  • Separation of real-time and high-level computing
  • Camera and computer vision support
  • Home Assistant and Project Vapor integration
  • Future autonomous docking and charging
Roadmap

Next Milestones

  • Complete RC control testing
  • Install robust 5V power system
  • Integrate Raspberry Pi 5
  • Implement Pi-to-Arduino telemetry link
  • Add camera and vision processing
  • Home Assistant integration
  • Autonomous docking experiments
Why It Matters

A Mobile Vapor Node

Rover-001b combines embedded systems, robotics, mechanical design, power electronics, and software integration into one evolving platform. It serves as a practical engineering sandbox and a stepping stone toward a fully autonomous mobile assistant.
