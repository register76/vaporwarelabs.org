Project Vapor

A custom smart home platform built with Home Assistant, ESP32 nodes, intelligent lighting, occupancy sensing, and local voice control.

Overview

Project Vapor is my long-term effort to build a highly customized smart home ecosystem that combines automation, embedded systems, and industrial design into a cohesive user experience.

The platform uses Home Assistant as the central controller, with custom-built ESP32 nodes for lighting, presence sensing, voice interaction, and tactile control interfaces.

Key Features

🎙 Voice Control

Local voice satellites powered by Home Assistant Assist.

💡 Intelligent Lighting

WLED-based RGBW lighting with custom work and relaxation scenes.

👁 Presence Detection

mmWave sensors detect occupancy and automate room behavior.

🎛 Custom Controllers

Large encoder-based desktop interfaces with OLED displays.

🤖 Robot Eyes

Animated display modules that add personality and visual feedback.

📧 Email Automation

Email-triggered workflows using VaporWare Labs aliases.

System Architecture

  • Core Controller: Raspberry Pi 5 running Home Assistant OS
  • Voice Satellite: M5Stack Atom Echo
  • Lighting Nodes: ESP32 devices running WLED
  • Presence Nodes: ESP32-C3 + LD2410C mmWave sensors
  • Control Interfaces: Custom desktop controllers
  • Audio Nodes: Raspberry Pi-based network speakers
